# 📄 Corrective RAG System

An AI-powered **Corrective RAG** system that answers questions based on uploaded PDF documents.

## 🔄 How It Works

```text
PDF Upload
   ↓
Text Chunking
   ↓
Embeddings
   ↓
Vector Search
   ↓
Evaluate Retrieved Content
   ↓
Correct Query if Needed
   ↓
Generate Answer
   ↓
Source Pages

Tech Stack

* Python
* Streamlit
* LangChain
* Google Gemini
* HuggingFace Embeddings
* ChromaDB
* PyPDF

✨ Features

* PDF document upload
* Semantic search
* Retrieved content evaluation
* Query correction
* AI-generated answers
* Source page references
